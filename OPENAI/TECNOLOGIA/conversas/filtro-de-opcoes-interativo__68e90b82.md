# Filtro de opções interativo

- Tema: `TECNOLOGIA`

## Transcrição

### user

Como se chama, na programação, o tipo de filtro em que o usuário clica no filtro e aparecem as opções ?

### assistant

O tipo de filtro que você descreve — em que o usuário **clica** em um botão ou campo e então **aparecem opções para selecionar** — é conhecido na programação como um **dropdown** (ou **menu suspenso**).  

Dependendo do contexto e da tecnologia, ele pode ter nomes específicos:

| Contexto | Nome técnico mais usado | Descrição |
|-----------|--------------------------|------------|
| HTML / Front-end | `<select>` element ou **dropdown menu** | Exibe uma lista de opções quando o usuário clica. |
| UI/UX Design | **Dropdown list** ou **Combo box** | Campo que combina entrada de texto e seleção. |
| React / JS frameworks | **Select component** ou **Dropdown component** | Componente de interface (ex.: `Select`, `Dropdown`, `Autocomplete`). |
| Filtros em dashboards | **Filter dropdown** ou **Facet filter** | Menu suspenso usado para filtrar dados de uma tabela ou gráfico. |

Há variações mais específicas:
- **Multiselect dropdown** — permite selecionar várias opções.
- **Cascading dropdown** — em que a escolha de uma opção altera as opções do próximo filtro.
- **Autocomplete dropdown** — exibe opções conforme o usuário digita.
