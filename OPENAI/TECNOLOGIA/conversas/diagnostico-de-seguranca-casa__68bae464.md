# 🎯 Critério de Pontuação do Diagnóstico Casa Segura

## 1) Modelo geral
- Cada pergunta vale **0 (Não)** ou **1 (Sim)**.
- O valor é multiplicado pelo **peso da pergunta**.
- Perguntas **não aplicáveis** (por tipo de residência) **não entram no denominador**.
- Resultado final é **normalizado em 0–100**:
  
  `score_final = 100 * (soma(pesos_acertados) / soma(pesos_aplicáveis))`

- **Níveis de risco** (sem bandeiras vermelhas):
  - **0–49**: Alto risco  
  - **50–74**: Médio  
  - **75–89**: Baixo  
  - **90–100**: Ótimo

## 3) Multiplicadores de vulnerabilidade (opcionais, recomendados)
Se o usuário indicar **idosos** e/ou **crianças** em casa, aplicar os multiplicadores **apenas aos pesos das perguntas relevantes** (limitando o efeito total a **+20% por categoria**).

- **Idosos presentes**

  - Preparação para emergência (Q9): **×1,15**  
  - Ergonomia/circulação (Q1): **×1,10**

- **Crianças presentes**  
  - Químicos/medicamentos (Q4): **×1,25**  
  - Água (Q5, risco de afogamento – se houver pergunta específica, aplicar também): **×1,25**  
  - Elétrica (Q7): **×1,15**  
  - Acesso (Q6, CG-3, CI-2): **×1,10**  
  - Sacada (AP-1): **×1,25**

> Implementação: aplique os multiplicadores **antes** do somatório e **cap** (+20%) por categoria para evitar distorções.

## 4) “Bandeiras vermelhas” (falhas críticas)
Independente do score percentual, se qualquer condição abaixo for **Não**, classificar o resultado final como **RISCO CRÍTICO**:

1) **Gás perigoso** (CI-1 = Não): botijão sem ventilação **ou** mangueira/válvula vencidas/danificadas.  
2) **Crianças + Sacada sem proteção** (AP-1 = Não **e** crianças = Sim).  
3) **Crianças + Químicos acessíveis** (Q4 = Não **e** crianças = Sim).  

> Você pode acrescentar outras flags depois (ex.: ausência de rota de fuga em prédios **+** detector ausente), mas as 3 acima já capturam os maiores riscos de gravidade imediata.

```js
    "Casa geminada": ["Q1","Q2","Q3","Q4","Q5","Q6","Q7","Q8","Q9","CG1","CG2","CG3"],
    "Sobrado": ["Q1","Q2","Q3","Q4","Q5","Q6","Q7","Q8","Q9","SB1","SB2","SB3"]
  };
  const aplicaveis = new Set(grupos[tipo] || Object.keys(base));

  // 3) Aplicar multiplicadores (cap +20% por categoria)
  const mult = {...base}; // começa igual ao peso base

  // idosos
  if (temIdosos) {
    // quedas e ergonomia
    ["Q3","SB1","SB2","SB3","AP1"].forEach(id => { if (mult[id]) mult[id] *= 1.25; });
    if (mult["Q9"]) mult["Q9"] *= 1.15; // preparação
    if (mult["Q1"]) mult["Q1"] *= 1.10; // ergonomia
  }
  // crianças
  if (temCriancas) {
    if (mult["Q4"]) mult["Q4"] *= 1.25; // químicos
    if (mult["Q5"]) mult["Q5"] *= 1.25; // água
    if (mult["Q7"]) mult["Q7"] *= 1.15; // elétrica
    ["Q6","CG3","CI2"].forEach(id => { if (mult[id]) mult[id] *= 1.10; }); // acesso
    if (mult["AP1"]) mult["AP1"] *= 1.25; // sacada
  }

  // 4) Somatório
  let somaPesos = 0, somaAcertos = 0;
  for (const id in base) {
    if (!aplicaveis.has(id)) continue;
    const peso = mult[id] ?? base[id];
    somaPesos += peso;
    const ok = respostas[id] === true; // true = Sim, false = Não
    if (ok) somaAcertos += peso;
  }

  // 5) Score percentual
  const score = somaPesos > 0 ? Math.round((somaAcertos / somaPesos) * 100) : 0;

  // 6) Bandeiras vermelhas
  let riscoCritico = false;
  if (tipo === "Casa isolada" && respostas["CI1"] === false) riscoCritico = true;                // gás perigoso
  if (temCriancas && tipo === "Apartamento" && respostas["AP1"] === false) riscoCritico = true; // sacada
  if (temCriancas && respostas["Q4"] === false) riscoCritico = true;                            // químicos

  // 7) Nível
  let nivel;
  if (riscoCritico) nivel = "CRÍTICO";
  else if (score <= 49) nivel = "ALTO";
  else if (score <= 74) nivel = "MÉDIO";
  else if (score <= 89) nivel = "BAIXO";
  else nivel = "ÓTIMO";

  return { score, nivel, riscoCritico };
}
```
