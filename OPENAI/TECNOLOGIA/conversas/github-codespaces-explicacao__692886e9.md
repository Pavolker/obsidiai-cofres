**GitHub Codespaces** é um ambiente de desenvolvimento hospedado na infraestrutura do GitHub, baseado em *containers dev* com VS Code rodando na nuvem. Ele permite iniciar um projeto imediatamente, sem configurar nada localmente.

A frase **“Start coding with Codespaces – Add a README file and start coding in a secure, configurable, and dedicated development environment”** aparece quando você cria um repositório novo e significa:

**1. Criar o README**  
O GitHub sugere adicionar um arquivo README.md para iniciar a documentação mínima do projeto.

**2. Iniciar um Codespace**  
Com um clique, você abre o repositório em um ambiente completo de desenvolvimento. Esse ambiente possui:

- editor baseado em VS Code;  
- terminal Linux;  
- recursos de CPU e RAM alocados pelo GitHub;  
- extensões pré-instaladas;  
- possibilidade de configurar o ambiente com um arquivo *devcontainer.json*;  
- isolamento de máquinas locais (tudo ocorre na nuvem).

**3. Ambiente seguro e configurável**  
O GitHub executa tudo dentro de containers isolados. Isso evita conflitos de versões e problemas de instalação no computador local.

**4. Objetivo prático**  
Permitir que você comece a programar imediatamente, sem instalar dependências, SDKs, runtimes ou ferramentas no seu computador.
