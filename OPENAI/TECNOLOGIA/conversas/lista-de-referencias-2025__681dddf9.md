### ⚙️ **Opção 2: Script Shell (Linux/macOS)**

Salve o seguinte script em um arquivo chamado `create_md_files.sh`:

```bash
#!/bin/bash

declare -a titles=(
"Introductory paper on SMEs and Responsible Business Conduct – 2025"
"Everything You Need To Know About Prato's Textile Industry – 2025"
"Tiruppur gears up for next phase of growth – 2025"
# (... continue com os 41 títulos ...)
)

for i in "${!titles[@]}"; do
    num=$(printf "%02d" $((i+1)))
    title="${titles[$i]}"
    filename="${num}-${title// /-}.md"
    filename="${filename//–/}"  # Remove traço longo
    filename="${filename//[^a-zA-Z0-9\\-]/}" # Remove caracteres especiais

    echo "# ${title}" > "$filename"
    echo -e "\\nAno: ${title: -4}" >> "$filename"
done
```

Execute com:
```bash
chmod +x create_md_files.sh
./create_md_files.sh
```

### 🐍 **Opção 3: Script Python (Recomendado para multiplataforma)**

Crie um script chamado `create_md_files.py`:

```python
import os

titles = [
    "Introductory paper on SMEs and Responsible Business Conduct – 2025",
    "Everything You Need To Know About Prato's Textile Industry – 2025",
    "Tiruppur gears up for next phase of growth – 2025",
    # ... continue os 41 títulos aqui ...
]

for i, title in enumerate(titles, 1):
    num = f"{i:02d}"
    sanitized_title = ''.join(c if c.isalnum() or c in (' ', '-') else '' for c in title)
    filename = f"{num}-{sanitized_title.replace(' ', '_').replace('–','')}.md"
    with open(filename, 'w', encoding='utf-8') as f:
        f.write(f"# {title}\\n\\n")
        f.write(f"Ano: {title[-4:]}\\n")
```

Execute com:
```bash
python create_md_files.py
```

### ✅ **1. Manualmente (rápido, se forem poucos arquivos)**

### ⚙️ **2. Automaticamente com um plugin ou script dentro do Obsidian**

Você pode usar **plugins como o Templater ou Obsidian Advanced URI**, ou simplesmente **colocar um script Python/Shell fora do Obsidian que crie os `.md` diretamente na pasta do Vault**.

#### Exemplo com Script Python (Recomendado)

Se seu Vault está localizado em, por exemplo:  
`~/Obsidian/Vault-Pesquisa`

Você pode rodar este script (adaptado da resposta anterior):

```python
import os

vault_path = "/Users/seunome/Obsidian/Vault-Pesquisa"  # substitua pelo caminho do seu Vault

titles = [
    "Introductory paper on SMEs and Responsible Business Conduct – 2025",
    "Everything You Need To Know About Prato's Textile Industry – 2025",
    "Tiruppur gears up for next phase of growth – 2025",
    # ... continue com os 41 títulos
]

for i, title in enumerate(titles, 1):
    num = f"{i:02d}"
    safe_title = ''.join(c for c in title if c.isalnum() or c in (' ', '-')).replace(' ', '_').replace('–','')

    with open(filename, 'w', encoding='utf-8') as f:
        f.write(f"# {title}\\n\\n")
        f.write(f"Ano: {title[-4:]}\\n")
```
