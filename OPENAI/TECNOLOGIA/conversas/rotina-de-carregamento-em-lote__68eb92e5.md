## Transcrição

### user

como se chama a rotina de carragar muitos arquivos de uma vez só ?

### assistant

Em programação, a rotina que **carrega muitos arquivos de uma vez só** é normalmente chamada de:

- **“Batch loading”** (ou *carregamento em lote*)  
  → refere-se ao processo de carregar vários arquivos simultaneamente ou em sequência automatizada, geralmente sem interação do usuário.

Outros termos usados, dependendo do contexto:

1. **Bulk import / Bulk upload**  
   → comum em bancos de dados ou sistemas web; significa importação ou upload em massa.

2. **Mass file loading**  
   → usado em pipelines de dados, ETL ou sistemas de armazenamento.

3. **Parallel loading**  
   → quando o carregamento é feito em múltiplas threads/processos para otimizar tempo.

4. **Data ingestion** (*ingestão de dados*)  
   → termo mais amplo, usado em engenharia de dados para designar o processo de coletar e carregar grandes volumes de dados (arquivos, APIs, streams).
