## ❓**Vantagem de desenvolver o aplicativo em Electron.js**

O **Electron.js** permite criar **aplicações desktop multiplataforma** (Windows, macOS e Linux) usando tecnologias web (HTML, CSS e JavaScript). A seguir, listo os **principais benefícios** desse caminho para o seu projeto:
