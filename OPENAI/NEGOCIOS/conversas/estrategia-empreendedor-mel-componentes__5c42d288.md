Faça o mapa mental desses tópicos : 1. Plano Estratégico
Definição: Documento que define a direção estratégica de uma organização, incluindo missão, visão, objetivos, metas e ações para alcançá-los.
Relação com os demais: Base para o Mapa Estratégico e o Balanced Scorecard; alinhado com o Modelo e Plano de Negócios.
Importância para o Empreendedor do Mel: Define a direção e os objetivos de longo prazo, orientando todas as ações da empresa.
2. Mapa Estratégico
Definição: Representação visual dos objetivos estratégicos e suas relações, organizados em perspectivas.
Relação com os demais: Deriva do Plano Estratégico; base para o Balanced Scorecard.
Importância para o Empreendedor do Mel: Facilita a compreensão e comunicação da estratégia, mostrando como os objetivos estão interligados.
3. Balanced Scorecard (BSC)
Definição: Ferramenta de gestão que traduz a estratégia em indicadores de desempenho, monitorando o progresso em relação aos objetivos.
Relação com os demais: Complementa o Plano e Mapa Estratégico; alinhado com o Modelo e Plano de Negócios.
Importância para o Empreendedor do Mel: Permite o acompanhamento e avaliação da estratégia, facilitando a tomada de decisões e ações corretivas.
4. Modelo de Negócios
Definição: Descrição da lógica de como uma organização cria, entrega e captura valor.
Relação com os demais: Base para o Plano de Negócios; alinhado com a estratégia.
Importância para o Empreendedor do Mel: Define como a empresa opera e gera valor, sendo fundamental para o entendimento e desenvolvimento do negócio.
5. Plano de Negócios
Definição: Documento detalhado que descreve todos os aspectos de um negócio, incluindo o Modelo de Negócios, mercado, concorrência, finanças, marketing, etc.
Relação com os demais: Complementa o Modelo de Negócios; alinhado com a estratégia.
Importância para o Empreendedor do Mel: Serve como um guia para a implementação do negócio, sendo útil para atrair investidores e parceiros.
