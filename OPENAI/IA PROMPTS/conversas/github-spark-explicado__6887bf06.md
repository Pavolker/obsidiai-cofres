### O que é e como funciona

1. **Prompt em linguagem natural → app funcional**  
   Você descreve a aplicação desejada com instruções em inglês, e o Spark gera automaticamente tanto o frontend quanto o backend, incluindo lógica de dados, autenticação e interface, tudo com **templating em React/TypeScript** citeturn0search4turn0search1turn0search0.

2. **Iteração diretamente no app**  
   Após a geração inicial, é possível refinar o aplicativo com prompts adicionais ou usar controles visuais. Alterações são refletidas imediatamente na visualização em tempo real citeturn0search1turn0search12.

3. **Ambiente de execução gerenciado**  
   O runtime do Spark cuida de armazenamento (key-value), hospedagem, autenticação via GitHub e integração com modelos de linguagem, eliminando a infraestrutura necessária tradicionalmente citeturn0search0turn0search5.

4. **Controle de código e repositório GitHub**  
   Cada aplicação (spark) é salva em um repositório GitHub com histórico completo de commits, GitHub Actions, Dependabot e possibilidade de abrir um Codespace para edição manual ou Colaboração com Copilot citeturn0search5turn0search12.

5. **Integração com modelos LLM**  
   O Spark utiliza o modelo Claude Sonnet 4 por padrão e permite adicionar recursos de IA diretamente no app (como sumarização, interações de chat, etc.), sem necessidade de gerenciar chaves ou endpoints externos citeturn0search5turn0search0.

6. **Compartilhamento e remix**  
   Você pode compartilhar sua aplicação com permissões de leitura ou escrita. Outros usuários podem “favoritar”, usar ou remixar o spark conforme suas necessidades citeturn0search0.

### Casos de uso comuns

- Protótipos rápidos (MVPs)  
- Ferramentas internas ou pessoais (rastreador de tarefas, dashboards, jogos simples)  
- Aplicações de uso pessoal ou comunitário com interface minimalista e foco em produtividade ou automação citeturn0search0turn0search11

### Limitações apontadas

- Melhor desempenho com prompts em **inglês**  
- Ainda não ideal para sistemas complexos e aplicativos corporativos com múltiplas integrações e requisitos de segurança robustos citeturn0search13  
- Pode gerar erros de interpretação ou vulnerabilidades comuns; revisão manual do código e testes são recomendados citeturn0search13
